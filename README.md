# コムデスク自動投入

Googleスプレッドシートの営業リストを、コムデスクへ自動で登録するツールです。
**VS Codeは不要**で、パソコン標準のターミナル／PowerShellだけで動きます。

お使いのパソコンに合わせて、次のどちらかを開いてください。

| パソコン | 開くファイル |
| --- | --- |
| **Windows** の方 | [README_Windows.md](README_Windows.md)（PowerShellで操作） |
| **Mac** の方 | [README_Mac.md](README_Mac.md)（ターミナルで操作） |

どちらも「上から順番にコマンドをコピー＆ペーストするだけ」で使えます。

---

※ 仕組みや他機能（Googleマップ収集・Slack・AIアシスタント等）の内部資料は、管理者向けに `docs/内部メモ.md` にまとめてあります。
