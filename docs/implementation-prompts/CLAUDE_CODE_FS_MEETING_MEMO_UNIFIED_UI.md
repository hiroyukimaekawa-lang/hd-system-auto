# Claude Code追加修正指示｜FS商談画面 右サイドバー「商談メモ」統合

## 対象

```text
/Users/maekawahiroyuki/hd-system-auto
```

今回の対象は、FS商談実行画面の右側サイドバーのみです。

既存の商談メモ保存、AI整理、商談履歴、DB、Obsidian連携、トークスクリプト本文は変更しないでください。

---

# 1. 現在の問題

現在、右サイドバーに以下が別々の大きなブロックとして存在しています。

```text
MEETING MEMO
殴り書きメモ
入力欄
過去メモ

REACTION ANALYSIS
反応・言質のAI整理
説明文
入力欄
反応と言質を整理して保存
アウト返し集
```

商談中に必要なのは「相手の発言をすぐに書くこと」が中心であり、
入力欄が2つあることで、

- どちらへ入力すればよいか分かりづらい
- 縦幅を使いすぎる
- 商談中に下までスクロールする必要がある
- AI整理の説明文が大きすぎる

という問題がある。

---

# 2. 完成形

右側は1つのパネルだけにする。

```text
┌─────────────────────────────┐
│ 商談メモ            自動保存 │
│                             │
│ ┌─────────────────────────┐ │
│ │                         │ │
│ │ 相手の発言・反応・懸念  │ │
│ │ 言質などをそのまま入力  │ │
│ │                         │ │
│ │                         │ │
│ └─────────────────────────┘ │
│ Enter：追加 / Shift+Enter：改行│
│                             │
│ [AI整理して保存]            │
│                             │
│ AI整理結果                  │
│ ┌─────────────────────────┐ │
│ │ 現在の要約・言質・懸念  │ │
│ └─────────────────────────┘ │
│                             │
│ ▸ 過去メモ                  │
│ ▸ アウト返し候補            │
└─────────────────────────────┘
```

---

# 3. 削除する表示

UIから以下の文言を削除してください。

```text
MEETING MEMO
殴り書きメモ

REACTION ANALYSIS
反応・言質のAI整理

質問したときの反応、相手が実際に言ったこと、
迷っている条件をそのまま入力してください。
```

機能を削除するのではなく、表示だけを簡略化する。

---

# 4. 見出し

右サイドバーの見出しは以下だけにする。

```text
商談メモ
```

右上に小さく:

```text
自動保存
```

または保存状態に応じて:

```text
保存済み
保存中…
未保存
```

を表示する。

英語のEyebrow表示は不要。

---

# 5. 入力欄を最優先で大きくする

右サイドバーの中で最も大きい要素をメモ入力欄にしてください。

現状より明確に縦幅を大きくする。

推奨:

```css
#meeting-memo-input {
  min-height: 220px;
  height: clamp(220px, 34vh, 380px);
  resize: vertical;
  line-height: 1.65;
  font-size: 15px;
}
```

画面が高い場合はさらに広く使えるようにする。

placeholder:

```text
相手の発言・反応・懸念・言質などをそのまま入力
```

余計な説明文を入力欄の外に置かない。

---

# 6. 入力欄は1つだけ

商談中の自由入力欄は1つに統合してください。

現在AI整理用に別textareaが存在する場合は、
商談画面上では非表示または廃止し、

```text
商談メモの原文
```

をAI整理の入力元として使用してください。

つまり:

```text
商談メモへ入力
↓
メモ保存
↓
蓄積された原文メモをAI整理
```

という流れにする。

AI解析用に同じ文章をもう一度入力させないこと。

---

# 7. Enter操作

既存仕様を維持する。

```text
Enter
→ メモ追加・保存

Shift + Enter
→ 改行

日本語変換確定中のEnter
→ 送信しない
```

既存処理を再利用する。

---

# 8. AI整理ボタン

独立した大きな「REACTION ANALYSIS」カードを削除し、
商談メモパネル内に1つのボタンとして配置する。

表示:

```text
[AI整理して保存]
```

または既存用語に合わせ:

```text
[メモをAI整理]
```

推奨は:

```text
AI整理して保存
```

ボタンは入力欄直下に配置。

幅は100%でもよいが、高さを取りすぎない。

```css
height: 46px;
```

---

# 9. AI整理結果

AI整理結果自体は削除しない。

入力フォームとは分けて、結果だけをコンパクトに表示する。

見出し:

```text
AI整理結果
```

初期表示で重要なもの:

```text
・現在の要約
・取れている言質
・残っている懸念
・次に確認すること
```

表示例:

```text
AI整理結果

HP制作には前向き。
電気は奥様確認が必要。

言質：
「HP自体は作りたい」

懸念：
電気料金と奥様確認
```

詳細解析項目が多い場合は:

```text
[詳細を見る]
```

で展開する。

AI結果の文字量でサイドバーが極端に長くならないようにする。

---

# 10. 過去メモ

「メモはまだありません」などの説明は小さくする。

メモが0件:

```text
まだメモはありません
```

だけでよい。

メモが存在する場合は初期状態で折りたたむ。

```text
▸ 過去メモ（5）
```

展開すると:

```text
11:15
HPは作りたいとのこと

11:22
奥様確認が必要
```

を表示。

商談中のメイン領域を過去メモ履歴で圧迫しない。

---

# 11. アウト返し集

現在の:

```text
このトークの反応・アウト返し集
```

は機能を残す。

ただし初期状態は折りたたみ。

```text
▸ アウト返し候補
```

必要な時だけ開けるようにする。

---

# 12. 右サイドバーの情報優先順位

上から:

```text
1. 商談メモ入力欄
2. AI整理ボタン
3. 最新AI整理結果
4. 過去メモ
5. アウト返し候補
```
